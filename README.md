## Projetos em Destaque

### 1. Lead Scoring B2B — Machine Learning para Priorização Comercial

Projeto end-to-end de Ciência de Dados para priorização automática de leads comerciais B2B, utilizando Machine Learning para estimar a probabilidade de conversão de cada oportunidade.

O projeto simula um problema real de negócio: apoiar o time comercial na identificação dos leads com maior potencial de conversão, tornando o processo de vendas mais orientado por dados.

**Principais entregas:**

* Análise exploratória dos dados;
* Tratamento e preparação das variáveis;
* Treinamento de modelo de classificação com LightGBM;
* Avaliação de performance com AUC aproximada de 0,83;
* Geração de score de conversão;
* Pipeline de inferência;
* Disponibilização do modelo com FastAPI;
* Containerização com Docker.

**Tecnologias utilizadas:**
Python | Pandas | NumPy | Scikit-Learn | LightGBM | FastAPI | Docker | Machine Learning | MLOps

**Repositório:**
[github.com/guilhermehrsilva/lead-scoring-b2b-mlops](https://github.com/guilhermehrsilva/lead-scoring-b2b-mlops)

### 2. Retail Pricing Analytics — Análise e Modelagem para Precificação no Varejo

Projeto de Ciência de Dados aplicado à precificação no varejo, combinando análise exploratória, engenharia de atributos, modelagem preditiva e simulação de cenários de preço.

O objetivo é demonstrar como dados transacionais podem apoiar decisões comerciais relacionadas a preço, demanda, receita e margem.

**Principais entregas:**

* Geração de base simulada de varejo;
* Análise exploratória de receita, margem, preço e demanda;
* Criação de variáveis de negócio;
* Modelo preditivo para estimativa de quantidade vendida;
* Avaliação com métricas como MAE, RMSE, MAPE e R²;
* Simulação de cenários de preço: -10%, -5%, atual, +5% e +10%;
* Comparação de impacto em receita, margem e volume;
* Dashboard em Streamlit;
* Consultas SQL para análise de negócio.

**Tecnologias utilizadas:**
Python | Pandas | NumPy | Scikit-Learn | XGBoost | Matplotlib | Streamlit | SQL | Machine Learning | Pricing Analytics

**Repositório:**
[github.com/guilhermehrsilva/retail-pricing-analytics](https://github.com/guilhermehrsilva/retail-pricing-analytics)

### 3. Academic Forecast — Modelo Preditivo para Estimativa de Base de Alunos

Projeto aplicado ao planejamento acadêmico, com foco em estimar a base de alunos da instituição e apoiar decisões relacionadas à organização de módulos acadêmicos.

A solução envolveu preparação, tratamento e validação de dados com Python, Pandas, NumPy e SQL Server, estruturando um pipeline analítico para comparação entre valores previstos e realizados.

**Principais resultados:**

* Desenvolvimento de modelo preditivo para estimativa da base de alunos;
* Previsão aproximada de 499 mil alunos frente ao realizado de 509 mil;
* Erro inferior a 2% entre previsão e realizado;
* Apoio ao planejamento acadêmico institucional;
* Validação de dados e comparação entre planejado x realizado.

**Tecnologias utilizadas:**
Python | Pandas | NumPy | SQL Server | Modelagem Preditiva | Validação de Dados | Data Analytics
